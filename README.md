# OmniMed

Adaptive Multimodal Generative AI Copilot for Evidence-Grounded Clinical Decision Support.

## MVP flow
1. Ingest synthetic patient data
2. Build structured Patient State
3. Retrieve evidence
4. Generate Clinical Brief
5. Clinician Accept/Edit/Reject
6. Create Care-Plan State
7. Add new data
8. Detect changes and assess care-plan impact
9. Generate reassessment alert

## Safety
Decision support only. No autonomous diagnosis, prescribing, or care-plan modification.
